# 🎂 BIRTHDAY

Website ucapan ulang tahun untuk Mamas.

## Struktur Folder

```
BIRTHDAY/
├── index.html
├── README.md
├── img/
│   ├── mamas1.jpg
│   ├── mamas2.jpg
│   ├── mamas3.jpg
│   ├── mamas4.jpg
│   └── mamas5.jpg
└── music/
    └── birthday.mp3
```

## Cara Deploy ke GitHub Pages

1. Masukkan 5 foto ke folder `img/` dengan nama persis `mamas1.jpg` ... `mamas5.jpg`
   (huruf kecil semua, GitHub Pages case-sensitive).
2. Masukkan lagu ke folder `music/` dengan nama `birthday.mp3`.
3. Upload / push semua isi folder ini ke repository GitHub.
4. Buka **Settings → Pages**.
5. Pada **Source**, pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
6. Tunggu 1-2 menit, website aktif di:
   `https://USERNAME.github.io/NAMA-REPO/`
